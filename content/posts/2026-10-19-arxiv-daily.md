## 1. SoftCache: Adaptive Step Size Caching for Diffusion Transformers

**作者**: Shimon Malnick, Nadav Orenstein, Ohad Fried, Shai Avidan  
**评分**: ⭐⭐⭐⭐ (9/10)  
**链接**: [http://arxiv.org/abs/2610.22369v1](http://arxiv.org/abs/2610.22369v1)  
**类别**: `cs.CV`

<!--more-->

### 🔍 核心内容
本文提出 SoftCache，一种针对扩散/流模型的软缓存加速方法。关键观察是 staleness 信号距阈值的'余量'可预测重用误差，据此让缓存步的步长随余量自适应伸缩——余量大时跳过多个调度节点，接近刷新时步长收缩回原步长，实现 3.5×–6.9× 加速且全面超越基线。

### ❓ 解决的问题
免训练缓存方法通过 staleness 信号二值决定'刷新或重用'，浪费了大量信息：信号距阈值的余量实际上预测了重用带来的误差，但硬切换机制无法利用这一连续信息。

### 🛠️ 方法
SoftCache 将硬切换改为软决策：以 staleness 余量直接设定每步前进的'距离'，大余量时跳跃多个调度节点、小余量时步长缩小回归原网格，使采样器脱离固定步长网格；方法免训练、无需逐骨干调参，可跨图像（FLUX）与视频（HunyuanVideo、Wan2.1）模型通用。

### 📊 效果
在 FLUX 图像生成及 HunyuanVideo、Wan2.1 视频生成上，3.5×–6.9× 加速范围内，四项保真度指标全面领先所有基线方法。

### 🤖 AI 评价
这是缓存加速方向一篇概念上很漂亮的论文：把一个被忽视的连续信号（headroom）转化为步长自适应机制，'软缓存'概念新颖且理论直觉强。免训练、零骨干特定超参、跨模态通用，工程友好度极高。潜在风险在于跳跃节点可能偏离原采样的理论保证，但在强实验支持下问题不大。预计会成为扩散加速的常用基线，影响力可观。

**标签**: 扩散模型, 缓存加速, 视频生成, 免训练

**类别**: `cs.CV`

### 🔍 核心内容
本文提出 Dynamics-aware Token Merging (DaTMe)，一种免训练的扩散模型加速框架。核心洞察是 token 重要性应反映其在去噪过程中是否'未解决'及是否承载结构信息，据此构建动态重要性图，自适应分配 token 合并角色，在压缩率约束下保持全图视觉保真度。

### ❓ 解决的问题
现有免训练 token 合并方法多以文本相关性决定保留区域，忽略 prompt 未提及的背景物体与局部细节，导致结构连贯性退化。如何基于扩散动态本身判定哪些 token 可安全合并仍是开放问题。

### 🛠️ 方法
DaTMe 从 Tweedie 去噪估计构建动态重要性图：时间信号度量相邻步预测净图的变化，结构信号捕捉局部高频内容（边界、细节）；两者结合后，重要 token 作为锚点保留，同时满足时间稳定与结构同质条件的 token 被选为安全合并候选。

### 📊 效果
在 PixArt-α 和 FLUX 上的实验表明，DaTMe 在各压缩率下保持全图视觉保真度，优于基于文本相关性的方法，尤其在背景与细节区域优势明显。

### 🤖 AI 评价
论文洞察深刻：将 token 合并决策从'文本驱动'转向'扩散动态驱动'，理论动机清晰，实现简单即插即用。时间信号+结构信号的双信号设计兼顾语义与几何，是对 token merging 文献的实质性推进。局限是结构高频信号可能在高度纹理区域误判，且仅在两个 DiT 上验证。总体而言是高效扩散生成方向一篇扎实的方法论贡献，实用价值高。

**标签**: 扩散模型, Token Merging, 图像生成加速
