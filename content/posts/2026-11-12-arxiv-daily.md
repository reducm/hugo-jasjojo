## 2. Contrastive Discovery: Open-Ended Scientific Discovery over Competing Explanations

**作者**: Ziang Liu, James J. Kim, Yijia Dai, Jennifer J. Sun  
**评分**: ⭐⭐⭐⭐ (9/10)  
**链接**: [http://arxiv.org/abs/2611.14514v1](http://arxiv.org/abs/2611.14514v1)  
**类别**: `cs.AI`

<!--more-->

### 🔍 核心内容
本文提出 Contrastive Discovery，将 LLM 科学发现 agent 的假设从单个命题 h 替换为对比集：一个科学问题搭配互斥且穷尽的竞争性解释。每个实验按其证据如何在对比集上重新分配信念来评分，信念集中到某一解释时问题被解决。

### ❓ 解决的问题
现有 LLM 科学发现 agent 多为逐点评估，只检验 h 对 ¬h，证据拒绝 h 时 agent 只知道某个解释不成立，却不知道证据支持哪个备选解释。

### 🛠️ 方法
对比集只改变 agent 提出和评分的单元，现有 agent 可直接复用：可用它重新评估已收集的证据，或引导搜索；实验评分基于证据在互斥解释间的信念重分布。

### 📊 效果
六个领域中 89% 信念变化最大的逐点候选是拒绝型；同样证据下对比集能为 73% 的这类候选解析出具体备选；以对比集引导搜索在同等实验预算下比逐点惊奇度多解决 67% 的问题；盲测中 38 位人类专家在 78% 已解决问题上选择同一解释。

### 🤖 AI 评价
这是一篇概念贡献清晰且实验扎实的工作，核心洞察有深刻的认识论基础：科学推理的本质是竞争性解释间的判别而非单假设证伪。对比集设计优雅，与现有 agent 兼容性强。人类专家盲测验证大幅增强了结论可信度。不足在于对比集本身的构造质量依赖 LLM 生成互斥且穷尽的解释，这一步的错误会传播；且当前主要在简化的发现场景验证。但方法论的普适性使其很可能被广泛采用。

**标签**: LLM Agent, 科学发现, 对比假设, 自动化科研, 认识论

## 3. When Does the Real Wiring Win? Testing connectome structure-function claims against unmeasured physiology

**作者**: Yeyuan Liu  
**评分**: ⭐⭐⭐⭐ (9/10)  
**链接**: [http://arxiv.org/abs/2611.14508v1](http://arxiv.org/abs/2611.14508v1)  
**类别**: `cs.LG`

<!--more-->

### 🔍 核心内容
本文系统检验连接组约束模型的结构-功能论断，指出真实布线与打乱布线的比较可能混淆「布线」与「调参方式」。作者分离三种估计目标（真实布线上调参迁移、各布线自调、限制于独立数据一致生理的调参），用合成真值、安慰剂零模型和三个果蝇环路模型测量 ML 已知偏差对生物学结论的影响。

### ❓ 解决的问题
连接组约束模型常被用来论证「真实布线优于打乱布线」，但连接组只固定谁连接谁，不固定兴奋性、增益、可塑性率等参数，模型者常调到真实布线模型能工作为止，使比较无效。

### 🛠️ 方法
定义 P1/P2/P3 三种估计目标分离布线效应与调参效应；用合成真值、安慰剂零模型和三个果蝇电路模型（蘑菇体、奖励惩罚多巴胺、头部朝向）量化欠调基线、权重继承、赢家诅咒等偏差的影响。

### 📊 效果
部分论断通过所有检验（分离奖励/惩罚多巴胺、头部朝向拓扑），但蘑菇体中真实 Kenyon 细胞输出布线在 P1/P2 下领先 0.09、在 P3 下反输 0.09；判决取决于 α'β' 细胞占比，按成像数据约 44% 时真实布线模型无法学习，暴露的是模型缺陷而非果蝇布线缺陷。

### 🤖 AI 评价
这是一篇方法论批判价值极高的工作，把 ML 社区熟知的调参偏差系统引入计算神经科学，直接挑战了一批已发表的结构-功能论断。P1/P2/P3 框架简洁而有力，「真实布线输给镜像连接组」等具体反例极具冲击力。对任何用连接组约束模型做生物学结论的研究者，这都是必读的方法论文献。缺点是案例限于果蝇三个电路，框架在哺乳动物全脑尺度上的可操作性未验证。

**标签**: 连接组, 计算神经科学, 方法论, 果蝇, 结构-功能

### ❓ 解决的问题

### 🛠️ 方法

**链接**: [http://arxiv.org/abs/2611.14505v1](http://arxiv.org/abs/2611.14505v1)  
**类别**: `cs.LG`

### 🔍 核心内容
本文提出 Continual-ARC，基于 ARC-AGI 三个版本构建的终身学习流：任务无需领域知识，相同任务在休眠间隔后以新实例回归，新任务持续到来；学习者按消耗反馈预算的比例计分，记忆型和权重型系统在统一标尺上比较，最后冻结测试记忆与泛化。

### ❓ 解决的问题
现有 agent 持续学习基准局限明显：只聚焦单一应用领域、每个实例只出现一次、默认单一学习器家族，记忆型和权重型系统从未在同一规模上公平比较。

### 🛠️ 方法
构建 ARC 任务流，实例上学习者可付费获取演示、提交答案或在 harness 内操作，错误提交可付费重试，按反馈预算消耗比例计分；流结束后冻结，分别在见过任务的新实例和未见任务上测记忆与泛化。

### 📊 效果
harness 持久化一般不提升记忆，除非有显式专家指导；多数 harness 方法学习量低于简单缓存任务演示的基线；无 harness 方法在未见任务上获益，而权重学习显示出实质收益。

### 🤖 AI 评价
这个基准设计哲学很正：统一计分让记忆型与权重型系统首次可比，且结论相当尖锐——当前主流 harness agent 的持续学习能力被一个简单的缓存基线打败，这对行业叙事是当头棒喝。发现「权重学习在未见任务上有实质增益而 harness 无」指出了未来的方向。局限是 ARC 任务族本身规模有限，结论外推到真实工作环境需谨慎；且「harness 不敌缓存」可能部分归因于所用模型的固有局限而非范式失败。

**标签**: 持续学习, ARC-AGI, Agent, 基准测试, 泛化

### 🔍 核心内容

### ❓ 解决的问题
现有深度学习框架缺乏把连续参数化曲线作为一等可学习对象的原生支持，连续特征嵌入、Kolmogorov-Arnold 网络等应用需要重复造轮子。

### 🛠️ 方法

### 📊 效果
